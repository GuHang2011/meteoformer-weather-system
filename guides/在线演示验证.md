# 在线演示验证

线上版本使用静态合成快照，主分支 `docs/` 为 GitHub Pages 发布目录。页面固定标注演示属性与快照日期；训练、导入、生成预报及阈值修改在本地完整版执行。

## 本地已验证

- Vue TypeScript 检查通过；完整模式与 demo 模式均构建成功。
- demo 模式的资源使用 `/meteoformer-weather-system/` 基路径，无根路径 `/api` 依赖。
- 五种要素、1–24 小时时效、固定色标、地图缩放、原始与连续网格均正常。
- NASA 地形与 Natural Earth 水系使用本地静态资源；地形／简图切换和署名显示正常。
- 模拟地形文件加载失败后自动显示简图，单点查询仍可用。
- 单点查询按最近格点提取，边界外查询明确报错，修改经纬度后可恢复。
- 预报和数据集下载为有效 NetCDF 文件；PNG 与所选变量、时效对应。
- 训练页展示实际完成的记录，无可触发的管理员登录、导入或训练按钮。
- 320、390、768、1440、1600 px 无横向溢出；所有页面及 hash 刷新正常。
- 1440 × 900、1600 × 1100 下时效条位于首屏内；训练记录页继续校验实际参数量及只读行为。
- 浏览器检查没有页面脚本错误、失败的 HTTP 响应或后端 API 请求。

脚本：`scripts/test-demo.cjs`。公开线上地址可用 `DEMO_URL` 环境变量传入同一脚本验证。测试使用独立临时浏览器上下文。

## 数据边界

快照保留真实实验的时间、指标和 24 小时网格结果。数据本身为人工合成，测试指标不能说明真实天气预报性能。集合降水频率尚未经概率校准。当前快照没有达到预设阈值的告警，空状态会说明这一事实。

所有可公开文件按明确清单复制；原学院系统、上传资料、Word 原件、账号、数据库、初始密码与本地模型权重均不进入公开仓库。
